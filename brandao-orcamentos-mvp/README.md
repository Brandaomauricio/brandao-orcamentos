# Brandão Orçamentos — MVP

Web app responsivo para instaladores criarem propostas profissionais em PDF ou link, organizarem compromissos e salvarem clientes, serviços, preços, condições comerciais e observações técnicas.

## Stack sugerida

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

## Rodar localmente

```bash
npm install
npm run dev
```

Abra:

```text
http://localhost:3000
```

## Próximos passos

1. Subir este projeto para um repositório GitHub chamado `brandao-orcamentos`.
2. Abrir no Codex e pedir para implementar por etapas.
3. Criar projeto Supabase.
4. Executar `supabase/schema.sql`.
5. Conectar variáveis de ambiente no `.env.local`.
6. Publicar na Vercel.
7. Configurar domínio `app.brandaoorcamentos.com.br`.

## Frase central

Preço definido com método. Orçamento apresentado com profissionalismo.
