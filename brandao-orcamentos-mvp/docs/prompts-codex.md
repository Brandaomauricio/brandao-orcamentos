# Prompts sugeridos para o Codex

## Prompt 1 — Base do app

Crie a base funcional do web app Brandão Orçamentos usando Next.js, TypeScript e Tailwind CSS.

O app deve ter:
- página inicial com logo, botão Novo Orçamento / Compromisso, cards Orçamentos, Agenda, Minha Conta, Ferramentas, Tutorial e dicas, Fale conosco;
- menu inferior com Início, Orçamentos, Novo, Agenda e Mais;
- identidade visual com preto grafite, cinza cimento, bege madeira, amarelo obra e branco técnico;
- estrutura inicial de rotas para orçamento, agenda, minha conta, ferramentas, tutorial, fale conosco e planos;
- layout responsivo para celular;
- componentes reutilizáveis para cards, botões, cabeçalho e menu inferior;
- dados mockados para montar a interface inicial.

## Prompt 2 — Supabase

Implemente integração com Supabase usando as variáveis NEXT_PUBLIC_SUPABASE_URL e NEXT_PUBLIC_SUPABASE_ANON_KEY. Crie um cliente Supabase reutilizável e prepare autenticação com e-mail e senha.

## Prompt 3 — Orçamentos

Implemente o fluxo Novo Orçamento com 7 etapas: Cliente, Serviço, Valores, Adicionais/Periféricos, Condições comerciais, Observações técnicas e Revisão.

## Prompt 4 — PDF

Implemente geração de PDF A4 da proposta comercial com logo, dados do instalador, dados do cliente, serviços, valores, condições comerciais, observações técnicas e valor total.

## Prompt 5 — Link público

Implemente link público da proposta com token único, botão Baixar PDF, botão Falar no WhatsApp e botão Aprovar proposta.
